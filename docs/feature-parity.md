## 0. 统一模型

Sporelink 不复制 Explore 的卡片类型字段。所有业务内容都是 `Node`，所有关系都是 `Edge`。

- `card` 节点的表层类型（根 / 深潜 / 发散 / 分支）由 Rust 根据入边关系派生，不落库。
- 父子、来源消息、分支点、平行关系、引用、包含、总结都是边。
- 导出只含节点与边；导入后重新派生表层类型。
- 文档、知识、消息、轮次、项目、文件夹也是节点；设置、模型、运行记录是系统节点。
